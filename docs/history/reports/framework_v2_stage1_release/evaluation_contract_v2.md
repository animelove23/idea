# 下一阶段类别审核合同草案

状态：供人工审核，尚未替换运行prompt、shot或旧参考。

文本抽取仍只包括明确肯定的实体与属性；属性槽color/material/size/shape/state，state为open/closed/wet/dry/broken/intact。动作、关系、数量、评价、否定和推测按原合同排除。排除不等于幻觉。文本明确large仍应抽取，视觉能否判断large由核验阶段处理。

对齐沿用保守规则：retained同主体完整等义；modified同一确定主体、同一属性槽且明确变值；跨槽为removed+added；主体未决的依附事实保持未决。另一侧原文仍存在而事实列表遗漏时标extraction_gap，禁止removed。当前prompt中的例外措辞只登记为X3a候选改动，此轮不修改。

视觉S要求指定主体和命题有明确图像支持；H要求明确缺席或可见矛盾；U用于分辨率、遮挡、指代、类别、材质或大小参照不足。不能把caption语境当图像证据，也不能把“没看清”自动当H。父实体H/属性S及父实体U/属性S均需复查，保留原始标签。

大小参照、材质可辨性、群体/实例、局部食物和人物/装饰物类别是重点裁决项。审核者可提出合同修订，但须另立版本，并让所有对照在同一修订合同上重评。

复核流程：M2/M3先只看文本；M5只看原图、命题和定位，不看原/steer身份、迁移状态或模型答案。已有20图已经用于开发，遮蔽答案的审核包也不是新的独立测试。建议双人独立标注并裁决；此轮未获得人工裁决，不把Astra或其他模型候选升级为human gold。
