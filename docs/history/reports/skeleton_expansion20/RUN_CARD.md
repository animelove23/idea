## 参考与分析边界

候选文本参考在M2调用前完成，图像候选在M5调用前完成；均由助手编写，未经独立人工确认。文本参考有群体拆分、身体部位和命名边界；视觉候选有“小物体是否可辨识”“large阈值”“主体定位是否足够”的判断空间。分歧本身须审核，不能默认参考永远正确。

原有计分器保留有限同义表。额外的“来源重叠但命名不同”标记只供审核，不据此改本轮F1。60条视觉事实是诊断抽样，类别频率不代表模型自然输出。

端到端同时输出全部事实的统计和预选60目标的“可匹配抽取、状态、真假”检查。后者不是全链Precision/F1，因为它不包含全部视觉参考和模型多报事实。

图像级bootstrap按原长度档分层、每档有放回重采样图像，seed=1994，2000次；区间仅描述此开发样本的抽样变化，不包含视觉模型/候选参考的系统误差。

## 冻结之后的修订规则

当前运行完成前不改模块合同。下一轮如修复引文校验粒度、对齐数组格式或视觉主体语境，每次只改一项。可确定性重放本轮保存的响应检查程序改动，但不能把重放声称为新的模型稳定性实验。
