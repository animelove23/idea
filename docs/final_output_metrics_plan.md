# 冻结框架的最终输出指标规划

优先级更新：本文件保留为后续方案评价口径备选。当前先执行[从缩短现象发现motivation的核心观察规划](motivation_first_observation_plan.md)：联合矩阵→语义成分→词语画像→案例审阅，发现稳定现象后再选择本文件中的评价指标。

状态：指标设计稿；不修改Final v1代码、prompt、few-shot、模型、历史参考与结果，也未执行新测评。计划仅在冻结输出之上新增独立的确定性统计层，不增加LLM调用。

目标：描述文本变短时，哪些实体/属性保留了、哪些受支持内容消失了、哪些幻觉被消除，以及词语组成如何变化。观察结果用于筛选steer改进假设，不直接证明缩短的因果机制。

## 1. 固定统计单位和标签语义

- 一条样本为同图、同提示、同生成配置下original与steer的一对文本。记录image_id、pair_id、condition_id、replicate_id及框架版本。
- 主语义单位为分解后的独立事实，分别统计实体E和属性A；重复提及不增加事实数。同一事实两侧的记录保留关联，但计算原始信息保留/损失时只从original侧计一次。
- S/H/U/P分别表示M5判为supported/hallucinated/uncertain/技术pending，均是预测标签。报告写“受支持事实”“预测幻觉”，不把它们自动称为人工核实的真/假。
- 受支持属性必须满足属性S、父实体S且strict_parent_supported_eligible=true。父实体U/P、父H但属性S等记录保留，并进入质量表。
- 衡量独立属性幻觉时，原始属性H还要求原始父实体S；父实体H导致的属性H另列“错误主体上的属性”，避免删掉一个错误实体连带多个属性被重复计为独立纠错收益。新增属性幻觉使用steer侧同样规则。
- 原始事实的文本对齐状态互斥为retained、removed、modified、unresolved；unresolved同时保留semantic/technical原因。modified不能直接算作removed。
- 主要长度W采用现有spaCy非空白、非标点的词数，不是模型token数。原始W=0或指标分母为0时输出null，并报告有效样本数。

记号：W0/W1是original/steer词数；N0,k是original侧已接收的k类事实数；S0,k是原始严格受支持事实集合；H0,k是上述口径的原始幻觉集合。

## 2. 主表：六组指标

实体与属性保持分列，不先加权合成一个“总分”。每个比率同时保存numerator、denominator和point/lower/upper，不能只导出百分比。

| 组 | 指标与输出键 | 定义 | 回答的问题 |
|---|---|---|---|
| 1 | 词数缩短率 word_reduction | (W0-W1)/W0；同时输出W0、W1、绝对变化 | 文本缩短了多少？负值表示变长。 |
| 2 | 受支持实体保留率 supported_entity_retention | S0,E中retained的数量 / count(S0,E) | 已确认受支持的原始实体还保留多少？ |
| 3 | 受支持属性保留率 supported_attribute_retention | S0,A中retained的数量 / count(S0,A) | 原始属性总体损失多少？包含主体消失的影响。 |
| 4 | 实体保留条件下属性保留率 conditional_attribute_retention | 在父实体原始S、对应steer父实体S、实体事实retained且指代映射明确的原始S属性中，属性retained数 / 该集合大小 | 对象还在时，是否专门丢失属性？与第3项必须同时看。 |
| 5 | 原始幻觉消除率 hallucination_elimination_{entity,attribute} | [H0,k中removed数 + modified且对应steer事实严格S的数] / count(H0,k) | 有效减少了多少原有幻觉？拆列删除和纠正两个分子。 |
| 6 | 新引入幻觉 new_hallucination_{entity,attribute} | 分别计added且steer H、原始S经modified变成steer H；输出两类数量、合计及100×合计/N0,k | 原有幻觉减少的同时，是否引入新错误？不以缩短后的词数作为唯一分母。 |

第2/3项只表示原始受支持事实的文本保留，不宣称两侧M5标签是独立验证：冻结框架会共享retained命题的视觉查询。若出现保留对齐却两侧标签矛盾，另列质量异常，不静默修改标签或挑选某一侧答案。

第4项不能用entity_matched字段直接代替：需要从bundles中的实体/事实对齐边及两侧账本重建父实体对应。matched未必满足明确保留及支持条件。父实体映射未决的属性不进入条件分母，但必须另报排除数量和占全部原始S属性的比例，防止条件样本越来越容易而分数虚高。

第5项的“纠正”只在映射明确、目标标签可用时计入；H→H的修改不算纠正，H→U/P进入未决。第6项中H→H修改属于旧错误延续，不重复算新引入。H0,k=0时消除率为null，而新增幻觉仍照常报告。

这六组定义为最终主表候选。质量字段必须伴随主表输出，但不再新增综合加权分数；每种steer条件的样本范围保持相同。

## 3. 解释现象的辅助指标

### 3.1 把属性消失分成清楚的类别

对每条原始严格S且removed的属性，按父实体状态分为：

1. 主体删除伴随属性删除：原始父实体事实removed。
2. 主体保留但属性删除：父实体满足第4项的保留条件。
3. 其他或未决：父实体修改、映射歧义、视觉状态无法确认等。

三类互斥、完整覆盖已判为removed的属性。分别输出数量、占全部原始S属性比例、占已删除S属性比例。“伴随”描述观察关系，不是因果证明。不把第三类硬分给前两类。

还输出每类受支持事实的retained/removed/modified/unresolved完整分布。研究“信息消退”时应直接看removed比例，不能用1-retention替代，因为其中还包含modified和unresolved。

### 3.2 修改与新增的视觉迁移

- 原始明确modified边按S/H/U/P→S/H/U/P列出计数矩阵，实体/属性分开，记录无法唯一对应的边数。
- added事实按S/H/U/P列出；新增S事实单列，不能拿新增内容抵消原始S事实丢失后只报净数量。
- 原始S事实removed、原始H事实removed分别列出，呈现收益与信息代价。
- 输出每侧严格S事实数量及每100词严格S事实密度。密度提高可能来自删词，必须与事实保留率和绝对数量一起看，不独立作为质量提升依据。
- 属性进一步按已有slot切片（如color、material、size、state）；只使用冻结schema中已有类别，不新增推断性属性类。

### 3.3 细粒度POS：做精确的词数净变化分解

对每种UPOS p，保存原始n0,p、steer n1,p，以及：

    POS缩短贡献 C_p = (n0,p - n1,p) / W0

覆盖全部UPOS时，sum(C_p)=word_reduction。某一词性增加则贡献为负；这是净词数构成，不是逐词删除对齐，也不是因果贡献。

展示可合并为五个互斥组：NOUN+PROPN、ADJ、VERB、ADV、其余全部词性。底层保存完整UPOS以便重算。另报各自文本中的每100词频率，但不能只报占比：总词数下降时，绝对数量减少的词性也可能占比上升。

结合粗粒度解释：

- 名词变少而实体保留率较高：与实体表述减少/改写相容，不直接等同于实体被删。
- 形容词变少且条件属性保留率降低：与对象仍在但属性信息收缩相容；形容词不等于属性事实，需回查事实及其证据跨度。
- 动词、副词减少：记录为词语层变化；当前框架未建动作/关系事实，不能据此计算动作/关系的语义损失率。

可辅助记录每实体提及次数及重复提及量sum(max(mention_count-1,0))，但M2提及覆盖本身不完整，所以这只是表述变化代理，不能据此把减少的文本全部命名为“冗余”。事实来源与词语链接使用现有跨度，不新增LLM词对齐。

### 3.4 位置切片

按原文事实首次有效证据位置划分前/中/后三分之一，分别统计S事实删除率，并保存各位置原始S事实分母。重复提及仍只计一个事实，缺少有效锚点另列。

尾部删除集中可作为后续检查截断的线索；当前stop_reason常为unknown且无完整生成轨迹，不能把它直接判成提前EOS或max_tokens截断。

## 4. 未决和测量质量：必须与每张结果表同行

| 字段组 | 分母与含义 |
|---|---|
| 输入及运行覆盖 | 预先固定图像/文本对总数、完成数、缺失/失败数；失败样本不能默默从实验规模消失。 |
| 分解质量状态 | 接受的E/A数量、隔离记录数、带issues的caption比例；没有额外参考时不能据此估计真实漏抽率。 |
| 对齐未决 | 按E/A、original/steer记录semantic_unresolved和technical_unresolved数量/占各侧接受事实的比例。 |
| 视觉未决 | U与P分开；报告事实级计数，并附唯一视觉命题数，说明共享查询使两者分母不同。 |
| 父实体约束 | 属性S而父非S的数量、父标签分布、严格统计排除ID和比率。原始标签保持不变。 |
| 条件分母覆盖 | 第4项有效属性数 / 全部原始S属性数，及父实体删除、修改、未决等排除原因。 |
| 实验身份 | 框架/profile/prompt/模型/输入哈希、生成条件、重复运行编号。 |

原始S集合固定时，设N=|S0,k|，R/D/M/U是原始事实的四种对齐状态数量：

    retention_point = R/N
    retention_alignment_range = [R/N, (R+U)/N]
    removal_point = D/N
    removal_alignment_range = [D/N, (D+U)/N]

这里只表达未决对齐的最坏情况范围，不是置信区间，也没有涵盖M2漏抽和M5误标。语义未决与技术未决对范围的贡献分别保存。不能把视觉U补成S/H，也不能删去对齐U后报一个更好看的点估计。

幻觉消除另保存known_removed、known_corrected、alignment_unresolved、modified_target_visual_unresolved以及其他未决数量。可由这些未决项形成保守范围，但不能直接复用上述“删除上界”冒充“消除上界”。

模块测评作为单独质量卡，不混入现象指标：M2实体/属性P/R/F1与引文合法率；M3实体映射及事实状态F1、有效覆盖和技术未决率；M5实体/属性三分类一致率、Macro-F1、逐类召回、错误确定判断数。每项标明参考来源、评审状态及数据集；当前旧候选参考结果不等于人工金标准确率。

## 5. 汇总方式和实验原则

- 先按图像/文本对算指标。主报告按图像等权汇总；多次生成先在同图同条件内聚合，附有效图像数。补报汇总分子/分母得到的micro结果，让读者看到长文本权重的影响。
- entity/attribute始终分列；不能由实体数量占比决定综合“质量”结论。
- 若估计区间，拟按图像进行配对bootstrap，保留同图所有条件和重复运行作为一个簇；与第4节的未决范围分列。没有足够独立图像时仅展示描述统计。
- 比较steer条件时，固定模型、提示、图像、解码、生成长度上限等，首轮只改变一种steer因素。数据切片是事先约定的分析视角，不等于新增实验干预。
- 后续若检查“仅仅变短”的解释，单独设计长度控制实验；不能看到相关曲线后直接宣称steer的独立因果收益。
- 先报告自动标签结果，再在明确抽样的人工复核层上检查关键结论是否稳定；审阅记录作为独立overlay，冻结参考和原始输出不覆盖。

## 7. 如何从指标选择动机

| 可观察的组合 | 可以提出的后续假设 | 当前不能直接下的结论 |
|---|---|---|
| 词数下降，E/A保留较高，重复提及代理下降 | 表述压缩可能占较大部分 | 所有被删词都是冗余、完整语义无损 |
| 词数下降，实体保留较高，条件属性保留较低 | steer可能优先抑制属性表达；可考虑属性保护 | 属性损失必然由某个内部方向导致 |
| 实体删除较多，属性删除主要伴随主体删除 | 主体层信息覆盖值得优先保护 | 附属属性都是被独立抑制 |
| 幻觉删除/纠正较多，S事实损失较少，新幻觉较少 | 有较好的纠错—保留取舍 | 总体视觉准确率或因果效果已被证明 |
| S/H事实都大量删除，密度却上升 | 可能是广泛收缩而非选择性纠错 | 密度提高就代表steer更好 |
| 尾部删除集中 | 需要检查生成终止和长度限制 | 已证明提前EOS |

## 8. 与冻结实现的对应关系

- 已直接输出：两侧词数/POS计数；事实与对齐状态；视觉标签；严格原始S事实的保留/删除分布及范围；父实体不一致记录。
- 现有数据可确定性派生：POS缩短贡献、条件属性保留、删除类型分解、H删除/纠正/新引入、属性slot/位置切片、图像等权汇总及审计索引。需要新建后处理代码，当前计划没有宣称这些文件已实现。
- 必须重新按严格口径汇总：历史m6/中的conditional_true_attribute_retention、supported_per100_words等字段没有完整应用本计划的父实体和条件分母规则，不能直接更名充作新指标。
- 现有数据无法确定：生成提前停止的真实原因、未抽出事实的总体规模、动作/关系语义损失、真实视觉准确率。需要生成日志或独立标注；不额外调用LLM来补造答案。

实现时建立独立统计版本，读取Final v1冻结输出并写入新目录。先用手算小样本检验分母、属性主体约束、修改/删除互斥、空分母和POS贡献恒等式；再在当前三图输出上做完整性验证。不会改变冻结分析框架或偷偷刷新历史分数。
