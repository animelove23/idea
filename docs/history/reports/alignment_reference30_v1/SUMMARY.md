# 30 对真实样本：Alignment 测试结论

已完成新增 30 对标注及全部测试。对这份冻结参考，普通保留、删除、新增的判断较好；部分重叠和改值边界仍弱，实体不确定性的拦截也造成较多技术回退。

**参考由助手起草，未经用户审核。**本次数字是相对于这份参考的指标，不是独立人工 benchmark 的准确率。输入为助手按 v6 格式写定的事实，不是新一轮 Decomposer 输出；因此本次只测试 Entity + Fact Alignment，不代表端到端拆分质量。

## 测试设置

- 30 对真实 greedy Vanilla/Steer，60 条 caption，857 条主线事实，621 条参考对应；随机种子 20260911，排除上一轮 4 对，不按结果挑选。
- 沿用已有 8-shot；测试 caption 与合成 few-shot caption 精确重叠为 0。没有加入本批示例或在测试后调提示词。
- DeepSeek `deepseek-v4-pro`，temperature 0，thinking disabled，每阶段一次请求，最多 60 次；实际发出 59 次，一对因实体步骤失败而跳过事实步骤。
- 全部 59 次请求获得返回和 usage。失败样本是实体重复对应的结构错误，不是 API 超时。此次只测试一轮，不报告重复稳定性。
- 122 项本地测试通过；冻结代码、输入、参考与示例哈希检查通过，每个事实恰有一个主对应。参考对齐标签不进入测试请求。

## 主指标

| 指标 | Precision | Recall | F1 |
| --- | --- | --- | --- |
| Alignment Edge（含 ∅ 端点） | 83.36% | 83.90% | **83.63%** |
| 对应边与状态联合正确 | 78.40% | 78.90% | **78.65%** |
| 仅两侧都有 fact 的对应边（辅助） | 93.39% | 90.21% | 91.77% |

Edge 的 TP 为 521，预测 625，参考 621；联合 TP 为 490。主指标包含单侧 added/removed 对应；辅助的两侧边指标不涵盖删除、新增、单侧技术回退，不能代替主指标。多对多作为一组对应，不展开成多条正确边。

Status Macro-F1 为 **60.94%**。这里每个原始 fact 计一次，857 个事实为固定分母；所以 retained / modified 等双侧参考会各贡献一个事实状态。

| 状态 | 参考事实 support | Precision | Recall | F1 |
| --- | --- | --- | --- | --- |
| retained | 392 | 94.57% | 88.78% | 91.58% |
| removed | 240 | **95.48%** | 79.17% | 86.56% |
| added | 140 | 94.96% | 80.71% | 87.26% |
| modified | 4（仅 2 条对应） | 0% | 0% | **0%** |
| ambiguous | 81 | 37.93% | 40.74% | **39.29%** |

Modified 样本只有两条对应：发球阶段变化、several/few 数量表达变化。模型分别处理为 ambiguous 或 retained，没有命中参考 modified；这两个边界本身需要用户审核，不足以估计一般改值能力。Macro-F1 下降主要由 modified 和 ambiguous 拉低，不应被 retained 占比较多掩盖。

## Removed Precision 与误删除

预测 removed 共 199 条，参考也为 removed 的有 190 条，Removed Precision = **190/199 = 95.48%**。

参考认为仍完整表达的误删除为 **2/199 = 1.01%**：

| 样本 | 被判 removed 的事实 | Steer 仍有的依据 |
| --- | --- | --- |
| 69584 | Clouds are present. | a cloudy sky |
| 303713 | The crowd watches the game. | spectators |

这两例是当前事实表中的语义展开/漏列边界：cloudy 与云、spectators 与观看。参考给了 extraction_gap，模型都判 removed，gap recall 为 0/2。它们不是通过运行本轮 Decomposer 验证的漏拆错误，且只有两例，需人工确认边界。

另有 **4 条部分保留、3 条身份不可裁决** 被判 removed。若把这 7 条全部计为误删除，保守上界为 **9/199 = 4.52%**。因此报告 FRR 为已确认值 1.01%，同时给出 4.52% 上界，不把有争议的情况算成“安全删除”。完整名单在 REMOVAL_REVIEW.md。

## 程序失败与语义判断分开记录

- 实体步骤：29 对通过、1 对失败；失败原因为一个实体被用于多个对应组。
- 事实步骤：15 对通过程序契约、14 对有被拒绝的配对、1 对因实体步骤失败而未执行。
- 技术回退影响 **78/857 = 9.10%** 的事实：52 条来自校验拒绝，26 条来自实体步骤整体失败。全部留在主指标分母，不因参考也是 ambiguous 就获得正确分。
- 44 条被拒绝的原始对应中，35 条因为实体不确定、4 条因为缺少可定位实体、3 条因为参与对象不一致、2 条因为槽位不一致。原始模型提议均已保存。

这说明接下来值得优先审查的是“实体身份不确定是否应阻断该属性/关系的所有判断”，以及 partial_overlap、modified、removed 的边界。本轮只测试，未依据测试标签修改校验器或提示词。

## 解释限制

参考的事实及配对由同一助手编写，部分等义事实措辞一致，可能比独立模型输出更容易配对。少数合取空间描述仍按组保留；身份、泛化、近似数量词与词义展开均有标注者判断。部分 caption 曾在早期定性分析中出现。这些限制和 modified 的极低 support 意味着当前结果适合作为可审核的开发测试，不能直接作为论文最终性能。

Removed precision 较高也不表示所有删除都检出：removed recall 为 79.17%，另有技术回退和 ambiguous 未决事实。不能把通过程序的 15 对称为语义全对，也不能把事实回退率当作模型幻觉率。
