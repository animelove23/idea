# 从输出缩短现象发现motivation：核心观察规划

当前主线：先观察steer引起的输出变化由哪些语义成分共同构成，再从稳定的现象提出模型或steer模块的改进假设，最后设计验证指标与干预实验。

本文件替代“先定六组方案评分指标”的优先级。`final_output_metrics_plan.md`保留为后续评价口径备选。当前不修改冻结的Final v1框架，不新增LLM分析模块，不训练或修改steer，不重新运行实验。

## 1. 首轮只回答三个问题

1. 文本变短的样本中，受支持信息和幻觉分别发生了什么？同样的缩短是否对应不同语义结果？
2. 这些结果主要由实体消失、属性消失、内容替换，还是表述数量变化构成？哪些现象经常同时出现？
3. 哪些现象在多张图像、不同缩短程度下反复出现，值得作为下一阶段的motivation？

观察单位是同图同提示下original/steer文本对。先固定一个模型、一个steer设置、一个解码配置，使用预先固定的完整样本集合；先不同时扫描强度、层、方向、多个生成配置。只有完成现象观察，才选择一个假设和一个干预变量。

S/H/U/P表示视觉模块预测的supported/hallucinated/uncertain/技术pending。所有“受支持信息/幻觉”均指该预测口径；关键motivation需要回看原图和文本，不能只从自动计数推出结论。

## 2. 核心产物一：长度分层的语义变化联合矩阵

采用用户示例的思路，分别展示变短、不变、变长三张矩阵。长度使用冻结框架的非空白、非标点词数W；变短W1<W0、不变W1=W0、变长W1>W0，不事后调整阈值。

每张矩阵：行是幻觉命题集合变化，列是受支持命题集合变化。命题键必须包含entity/attribute类型、主体对应和属性值，不能仅用名称字符串或总数量判断集合是否相同。

矩阵的属性口径与成分表一致：A-S要求属性及父实体S；独立A-H要求属性H且父实体S。错误主体上的属性作为伴随项单列，其他父实体未确认的属性保留未决状态，不静默视为不存在。实体E-S/E-H覆盖已明确判定的实体事实。

| 幻觉变化 \ 受支持信息变化 | 不变 | 只增加 | 只减少 | 有增有减 |
|---|---|---|---|---|
| 只减少 | 候选选择性去幻觉 | 去幻觉伴随受支持内容增加 | 去幻觉伴随受支持内容损失 | 去幻觉伴随内容替换 |
| 不变 | 候选表述压缩区 | 受支持内容增加 | 受支持内容受损而幻觉未变 | 受支持内容替换 |
| 只增加 | 原有受支持内容保留但出现新幻觉 | 两类内容同时增加 | 信息损失伴随新幻觉 | 内容替换伴随新幻觉 |
| 有增有减 | 幻觉内容替换 | 幻觉替换与受支持内容增加并存 | 幻觉替换与受支持内容损失并存 | 两类内容均发生替换 |

表内的文字只是观察描述，不是最终机制类别；实际输出每格为样本数、占该长度分层全体样本比例，以及若干可回溯样本ID。也可附可判定样本内的条件比例，但不能代替全体分母。

必须同时保留“不变”格中的两个子计数：

- 前后都没有该类已判定事实。
- 前后存在该类事实，且内容集合不变。

例如“原本无幻觉且依然无幻觉”的缩短样本，不能算去幻觉成功；它却很适合观察没有幻觉可删时，模型删掉了什么。

### 分类采用新增/损失事件，而非净数量

对S和H分别记录G（获得/新增的原子命题数）与L（不再表达的原子命题数）：

| 条件 | 集合变化 |
|---|---|
| G=0且L=0 | 不变 |
| G>0且L=0 | 只增加 |
| G=0且L>0 | 只减少 |
| G>0且L>0 | 有增有减 |

实体由dog改成cat，即使实体数量相同，也可能是一个旧实体命题退出、一个新实体命题进入，不能只据数量记为不变。语义等价改写则由已确认retained对应视为同一个事实。

与冻结对齐状态衔接：

- removed：原命题退出，按其原始视觉标签记S或H的loss。
- added：新命题进入，按其新视觉标签记S或H的gain。
- modified：保留原始modified事件及两端事实；在原子命题集合账目中记旧值退出、新值进入。例如错误颜色改成受支持颜色形成H-loss与S-gain，同时标记为同一条纠正边，不能当作两个独立原因。
- retained：同一语义命题不记gain/loss。若两侧标签冲突，记录视觉一致性问题，不把评判器变化当成内容变化。
- unresolved、U/P、父实体约束不满足或无法明确对应：不能自动补成gain/loss为0。

主图保留4×4确定分类格，另列无法确定行/列的样本数和原因；全体长度分层分母不删除这些样本。只有未决项不可能改变分类时，才可保留确定格，例如已有明确gain与loss的“有增有减”不会被额外未决项改成单向变化；否则记录候选格与已知事件，不能凭部分信息宣称“不变”。

矩阵按样本计数，所以受支持集合可包含带类型的E/A事实，而不会按实体数量给样本加权；下一份成分表必须把E/A拆开，揭示跨成分的替换。

## 3. 核心产物二：每个矩阵格的语义成分画像

对全体缩短样本以及占比较大、现象有解释价值的矩阵格，输出下面的成分表。首轮不把所有slot都展开，也不把每一种组合设成新机制。

| 成分 | 原始数量 | 保留 | 退出/损失 | 新进入 | 修改配对 | 未决 |
|---|---:|---:|---:|---:|---:|---:|
| 受支持实体 E-S | | | | | | |
| 幻觉实体 E-H | | | | | | |
| 受支持属性 A-S | | | | | | |
| 主体受支持的幻觉属性 A-H | | | | | | |

属性S采用严格父实体规则。错误主体上的属性另列伴随记录，不能当成多个独立属性幻觉反复累计。退出/新进入列按原子命题集合计，modified同时保留边ID，防止读表时将其当成与删除/新增完全独立的一组数量再相加。

每格同时给出每图平均数量、分子/可用原始成分分母，以及参与样本数。分母为0记null；不能由汇总数量比较“实体比属性更容易消失”，因为二者原本的数量不同。

### 第一优先级：属性损失由什么组成

对原始严格S属性的removed事件，只分三类：

1. 父实体removed，属性随主体一起消失。
2. 父实体明确retained且两侧受支持，但属性removed。
3. 父实体修改、身份未决或其他未决，暂不能归入前两类。

这一步直接区分“主体覆盖收缩”和“保留主体但丢掉细节”。它应先于设计属性保护分数或属性专用steer模块。不同类型可以在同一张图中共存，不给整个样本强行贴一个单一原因。

### 第二优先级：不把‘有增有减’当成噪声

在混合格中回查明确的modified边及新增/删除事实：

- 是错误属性被纠正，还是原有正确内容被换成别的正确内容？
- 是否出现具体名称变成上位概念、具体属性变模糊描述的例子？
- 是否同一类实体的主体身份被换掉，导致净数量不变但内容已经变化？

“语义泛化”“身份替换”等当前没有经测评的自动标签，先作为人工案例观察标签，保留文本证据与审阅状态。若反复出现，再决定是否需要扩展标签或新指标；不在冻结框架里临时加入LLM分类器。

## 4. 核心产物三：同一批样本的词语成分变化

在每个主要矩阵格上观察POS与提及分布，将词语变化与语义变化对应。

最小词语画像为：原始/steer词数、NOUN+PROPN数量、ADJ数量、VERB数量、ADV数量、其余词性数量，以及实体提及数量。底层保留完整UPOS，展示时使用这五个互斥组。

    各词性对净缩短的构成 = (原始该词性词数 - steer该词性词数) / 原始总词数

五组之和等于总词数缩短率；增加的词性允许负贡献。这是精确的净词数分解，不是对单个词的删除对齐，也不是语义事件的因果归因。

建议优先检查：

- S/H集合均不变却缩短：是否重复提及减少、句子结构更简洁、功能词或修饰表达减少？这只能先称为“当前E/A表示下的表述变化”；动作/关系不在当前事实范围内，不能宣布完整语义无损。
- E-S保留、A-S损失：ADJ等词语变化是否伴随已核查的属性消失？不能直接把所有ADJ都当作属性。
- E-S/E-H同时大量损失：名词及实体提及是否广泛减少，而不是仅减少错误对象？
- 原文尾部事实更容易消失：按首次有效证据位置统计前/中/后三分之一的删除比例，并检查具体例子。没有生成终止日志时，只报告尾部集中，暂不命名为提前EOS。

重复提及由M2已记录mentions提供，覆盖并不完整，因此只作代理。未连接到实体/属性的词保留为“当前语义范围未覆盖”，不能命名为无用词或冗余词。

首轮的成分分析采用可解释的语义与词语分解：实体、属性、标签、词性已有明确含义，先做分层、交叉表和成分画像。之后若需要发现尚未覆盖的样本结构，再考虑降维或聚类，并检查结果能否对应具体事实变化。

## 5. 四个说明性例子：同样变短，研究含义不同

以下为构造示例，仅解释观察口径，没有使用项目数据得出结论。

| 图像与文本前后 | 矩阵归类 | 成分观察 | 候选motivation |
|---|---|---|---|
| 图中有红车无狗；“A red car and a dog.”→“A red car.” | H只减少、S不变 | 删除H实体，S实体和属性保留 | 能否实现选择性去幻觉 |
| 同图；“A red car and a dog.”→“A car.” | H只减少、S只减少 | 同时删除H实体与S颜色属性 | 去幻觉方向可能伴随属性抑制，值得检验属性保护 |
| 图中有红车；“A red car is here. The car is red.”→“A red car.” | H前后为0、S不变 | 原子事实不变，重复表达减少 | 当前事实范围内可压缩的表述成分 |
| 图中有红车和蓝色自行车；“A red car is visible.”→“A blue bicycle.” | H前后为0、S有增有减 | 受支持实体及属性发生替换，净事实数可不变 | 需要区分信息保留与内容替换 |

第一个和第二个例子的幻觉数量下降相同；第三个例子没有幻觉可删；第四个例子事实数量不变。只看缩短率、幻觉净减少或事实总量，会把这些现象混在一起。

## 6. 从观察走向motivation，再走向指标

顺序固定为：

    联合矩阵定位主要现象
       → 成分画像定位变化发生在哪个语义层级
       → 回看原图/文本/对齐边，确认不是框架错误
       → 选少量可重复的观察形成假设
       → 为该假设定义专门指标和单变量干预实验

| 若实际观察反复出现 | 可形成的待验证假设 | 后续才考虑的设计 |
|---|---|---|
| H删除常伴随父实体仍在的S属性删除 | 当前方向可能把幻觉抑制与属性表达抑制耦合 | 属性成分保护或对方向做成分约束；届时定义条件属性保留与纠错取舍指标 |
| 没有H的样本也出现广泛S实体删除 | 方向可能包含一般性输出/内容覆盖抑制 | 检查方向中的普遍收缩成分；用独立长度控制实验检验 |
| 大量样本只减少重复表达而E/A集合不变 | 缩短的一部分可能来自可压缩表述 | 分开控制表述冗长与事实表达；届时设计事实条件下的表述指标 |
| S有增有减中反复出现具体→笼统 | 可能存在语义具体性收缩 | 先补足这类观察的明确定义和少量独立标注，再考虑层次化或具体性保护方案 |
| 删除集中在后段并随生成条件改变 | 终止/长度机制可能参与 | 获取真实终止日志后做单独生成机制实验 |

这些都是条件性研究路线，不是当前已发现的机制，也不是必须全部实现的模块。首轮只选1—2个有明确数据支持、与框架误差可区分、能够单独干预的motivation。

## 7. 首轮实际需要输出的文件

| 文件 | 用途 |
|---|---|
| observation_pairs.jsonl | 每对文本的长度分层、E/A按S/H的known gain/loss、modified配对、未知项、矩阵格或候选格、原文及原始fact引用 |
| change_matrices.csv | 三个长度分层的4×4计数、全体分母比例、不变格零基线拆分与未决汇总 |
| component_profiles.csv | 各格E/A×S/H的事件组成、属性删除三分类、有效分母，以及同批样本的POS组成 |
| motivation_cases.md | 各主要格按事先固定规则选例：典型、混合、反例与未决各保留，附原图、两版原文、事实变化、人工审阅备注 |

第一份汇报只展示三项核心结果：长度分层矩阵、重点格的语义成分图、对应词语画像与案例。上一版保留率、消除率等可以作为这些图的辅助计数口径，暂不作为预先设定的一整套方案排行榜。

所有图像都先进入长度分层总表；语义无法判定的样本保留在未决汇总，不选择性丢弃。相同图像的多条件/多次生成不是独立样本。当前只有一个预先固定的steer条件时，先做描述性观察，不把矩阵关联解释为因果。

本文件定义观察流程，不代表上述四个文件已实现或已算出新结论。实施采用独立后处理目录和版本，读取冻结的bundles、ledger、queue、verification、lexical记录，不覆盖冻结结果；先用构造例检查“数量相同但内容替换”“父实体消失”“U/P不能当不变”等分类边界。
