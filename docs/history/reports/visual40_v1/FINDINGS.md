这轮完成了40张随机原图、80条真实 caption 的文字流水线与逐事实视觉初标。共233次 DeepSeek 请求，关闭思考；图片和视觉标签均未发送。视觉判断由 Codex 助手完成，不是独立人工金标准。

## 可以直接观察的变化

- 长度：4847 → 2046 tokens，剩42.21%。
- 主线事实：723 → 494条，剩68.33%。
- 视觉 true：512 → 392条，减少23.44%；hallucination：113 → 49条；uncertain：98 → 53条。这是两侧抽出事实的数量，不是逐条对齐后的保留数。
- 每100 tokens 的真实事实密度：10.56 → 19.16。短句的真实信息更密集，但真实事实总量也减少；不能只用密度上升证明信息完整保留。

## 对齐迁移结果如何解读

按用户提供的公式，TSR=146/380=38.42%；HMR=64/65=98.46%；TCR=1/380=0.26%；NHR=33/124=26.61%。这些都是**已解决迁移**的比例。

TSR只计原样保留。21条 T_TO_T（仍为真但描述改变）也在分母中，所以1−TSR不能直接叫“真实事实删除率”：本轮 T_REMOVE=212、T_TO_T=21、T_TO_H=1、T_RETAIN=146。

HMR的分母只有65条已解决的原始幻觉，而所有原始幻觉有113条。剩余部分因对齐失败、身份/范围疑难或视觉冲突等没有进入迁移分母。**98.46%不能解释为整个40图消除了98.46%的幻觉。** 新增内容中还有33条幻觉，HMR本身也不惩罚新增幻觉，必须与NHR一起看。

属性和关系的已解决 TSR 分别为22.45%、23.08%，低于Object的55.95%。例如337055的短句保留人、行李箱和纹身，却省略真实的白衬衫、黑裙和铁轨；397351省略了胡萝卜颜色差异和背景货车。这些例子符合细节损失，但不足以排除评估器误差并确认某一类别存在系统性过度抑制。

## 评估器限制

1. 7/40对在实体对应校验阶段失败，其213条主线事实进入未解决项，没有被当作removed或从40图名册中删除。失败涉及mention不在原句、对应遗漏、单侧shape错误和非一对一对应；这是评估器问题，不能归因于steering。
2. 总UR=473/1217=38.87%；对齐未解决360/1217=29.58%，原始视觉uncertain为151/1217=12.41%。两者有交集，而且对侧uncertain还会阻断整个迁移，不能直接相加。
3. 各类UR：Object35.53%、Attribute26.67%、Action58.89%、Relation40.09%、Count54.72%。Action没有已解决的原始幻觉，HMR是N/A；Count的HMR仅基于1条原始幻觉，不能作稳定结论。
4. 自然语言fact仍有重复和非原子表达；本轮不修改已冻结输出，不事后去重提高分数。事实数量和TID仍受拆分粒度影响。缺失但未拆出的语义不在这些分母内。
5. 视觉标签是单次助手初标；模糊水果种类、局部遮挡、合成图中的人物数量、动作阶段、所有权和情绪等需要独立人工复核。未计算视觉标注准确率，因为没有独立视觉ground truth。

## 标注与复核口径

只问“这条事实在原图中存在／成立吗”：明确支持为true、明确不符为hallucination、证据不足为uncertain。关系和动作核对对应参与者及谓词，不能仅凭有该物体就判真。位置、颜色、数量、动作按具体事实核对；意图、享受、职业等不能凭常识补真。

实体类别与属性/关系的拆分边界需要保留说明：在可明确定位到同一个视觉对象时，部分关系/属性初标以该对象为锚点，类别是否正确在entity事实单独判断。例如256003中“小拖拉机”类别不符，但该工程车辆的位置和大小可以独立支持；388829中人的性别不清楚，但跪姿和背包可见。这是本轮原子语义标注口径，不能直接当成“每个自然语言句子连同所有修饰都被完全蕴含”的评估。审核时如采用严格整句蕴含，应统一复标受影响的依赖事实，不混用两种口径。

合成动作序列265462不能据多个人影确定五个独立人，人数标uncertain；灰度照片275717无法确认领带实际色相；这些不确定未强行计成幻觉。
