# Final v1：最后一轮修复与测试报告

代码、配置和结果已冻结。**M2确有改善，但M5实体仍未超过90%；本版是可复现的开发版本，未通过无需复核的语义研究验收。** 此处使用历史候选参考的一致率/F1，不能写成人工金标准确率。

## 最终选择与可运行入口

M2选择`owner`八例版本，开启唯一值引用修复及state词面校验。M5按输入事实类型固定路由：entity使用context证据合同，attribute使用proposition完整命题合同；每条命题一次调用，不逐样本查答案挑预测。M3保留原有规则与8-shot，三个阶段均显式`deepseek-flash`。

入口为`analysis_skeleton.final_v1.pipeline`，完整架构、模块数据去向和运行说明见[README](../../analysis_skeleton/final_v1/README.md)，冻结配置见[profile.json](profile.json)及[visual_routes.json](visual_routes.json)。新运行示例：

```powershell
.venv/Scripts/python.exe -m analysis_skeleton.final_v1.pipeline --profile outputs/final_v1_release/profile.json --pairs analysis_skeleton/fixtures/expansion20/pairs.jsonl --pair-id 303499 --output outputs/my_final_v1_run
```

输出必须是新目录。恢复同一任务用相同参数加`--resume`。最终入口拒绝跨运行缓存，保留同任务检查点恢复，以封闭旧缓存遗漏claim_type的风险。

## 错误究竟在哪里

1. **视觉类别及跨调用观察仍不稳定。** 399741中黑白斑点毛绒玩具被判为teddy bear；toy car命题被否定，但同图toy train的证据句又提到toy car。单条证据结构不能确保多条调用观察相容。
2. **主名词存在与整条命题真值仍有差别。** 22461的两把勺子，context证据明说只看到一把，旧编译合同仍输出supported；新合同能表达限定冲突，但也会把局部两人误当全图恰好两人。最终实体context保留这一已知限制，不能用于无复核的复合实体命题。
3. **指代、集合与真实主体身份。** 265462连续动作合成图的多个人形被当成多个独立滑板者；402623只有两把伞，却支持“另外两把”。这不只是noun是否识别成功。
4. **不可见信息和参考边界。** 环形谷物不能确认Cheerios品牌；只见桌面是否足以支持dining table、模糊处是不是手机等，存在证据和旧参考口径分歧。这些仍按原参考计错，不把争议自动改判正确。

按参考中预先存在的possible_composite_entity_claim分组，false组451条两合同均388/451=86.03%；true组57条由46/57变47/57。该标记只是粗略文字筛查，false绝不是“纯object金标”，也不能用它剔除样本抬高主分数。[独立原图审阅](../final_v1_m5/SEMANTIC_REVIEW.md)记录20条proposition剩余分歧；它与最终组合的82条分歧不是同一个集合。

## 结构与统计修复

从旧文件逐字恢复原文语境，540条单一定位、35条多个匹配、4条缺少匹配；歧义/缺失均有显式状态，未伪造锚点。属性使用自己的证据位置，代词场景保留完整caption。context只是定位信息，提示明确要求不能当成视觉真值。

每个接受事实保留抽取、对齐、视觉三条状态轴。技术错误不转换成语义uncertain。M5记录模型原始证据和最终判定规则；bbox仍是未独立验证的模型预测。跨两侧共享一次视觉查询仍依赖M3主体对齐，两个来源context均留存，但不宣称已独立验证相同视觉主体。

新增`strict_analysis.json`：属性只有自己与父实体均为supported、严格资格标志成立才进入受支持事实分母；列出所有排除ID，零分母为null。原始标签和旧`m6/`统计保留供复现。后续研究用严格统计及逐事实账本，不能把旧M6历史分母直接当成修复后的语义结论。

## 本轮停止点

按要求冻结最后一轮，不再继续扩大prompt变量。M2改善成立；M5实体超过90%的验收未通过。本版可以用于逐事实审计、定位错误、人工复核后的消退统计；当前自动视觉标签不足以单独支撑精细语义关系或steer改进结论。达到研究验收前，需要独立复核固定atomic object/attribute口径及类别边界，并用未参与迭代的图像评估，而不是继续在这579条候选参考上反复调到90%。
