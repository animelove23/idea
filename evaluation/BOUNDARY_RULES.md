# Alignment v1.1：语义对应与重复计数边界

Decomposer、caption、既有事实以及旧实验结果均不改变。本版修改 Alignment 请求规则和程序校验。来源是用户对草、静态距离、同义关系和木制重复描述的监督。

## 原文边界

- 花瓶 Vanilla 未表达 grasses；Steer 明确写出 flowers and grasses。按文本比较它属于 Steer 新增。不会根据图像是否真的有草提前删除这一 VLM 声称。
- standing close to each other 表示彼此站得很近；side by side 表示并排；approaching each other 才是正在相互靠近。距离、布局、移动不能随意替换，也不能仅因共享主体就视为同一属性改值。
- 同义关系由完整事实和原句决定。模型已经判断相同关系时，topped_with 与 has_on 的自由命名差异本身不足以否决；会留存不同slot名称的审查提示。
- modified 仍要求同一对象、同一窄语义槽位；已知不同属性维度（如age/color）不能直接 retained。身份、否定、语气、事实类型等硬约束仍保留。

## 重复边界

| 情况 | 处理 |
| --- | --- |
| 同一个输出行重复出现 | 合成一条输出记录，保留去重记录 |
| 同一对象、同一信息、相同语气/否定的多个重复fact | 可组成一个retained对应组，semantic_unit_count=1 |
| 完全相同的事实被多条retained重复引用 | 程序核对事实文本、对象、类型、槽位、语气/否定后成组 |
| 意义相同但用词不同的重复fact | 由模型明确给出等义对应组；程序不凭模糊字符串相似度自动合并 |
| wooden 与 appears to be made of wood | 不是完全重复：明确断言优先保留正确主对应，带推测的事实单独记录限定差异/关联引用 |
| 多条事实只部分重合，争用一个对侧fact | 可放入同一个ambiguous组，不因争用就自动当作删除 |
| 两个不同对象或不同值争用同一对应 | 不按输出先后任选一个，保留冲突待审查 |

`fact_alignment` 是主计数表，每个原fact仍恰好归属一行。`related_correspondences` 保存对已匹配fact的上下文引用，不再算一次主对应；它保留双方 assertion/polarity。保留该引用不意味着“似乎”已经等同于明确断言。原始fact层计数和语义对应组计数分别报告，避免将重复保留算两次。

## 原文出处

source必须确实出现在原caption中。一个短语出现多次不等于其语义对象无法辨认：当完整上下文及实体映射已明确时允许对应，同时保留 repeated_source_occurrence 警告；程序不擅自选定某一次字符位置。原文没有该片段、或者实体身份确实不确定，仍不能获得强行确定的对应。

## 验证范围

本地回归测试和对旧模型响应的离线回放验证的是校验器行为。它们不是新一轮LLM实验，不能用来报告新提示词的稳定性或语义准确率。宽松的字符串门槛也不会证明模型提出的对应一定正确，尤其是修饰语混入实体事实、部分语义保留等情况，仍需语义审核。
