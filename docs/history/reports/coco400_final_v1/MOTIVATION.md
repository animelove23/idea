# 从 COCO 400 结果提取的研究动机

本文件只根据本轮冻结框架的自动输出提出候选动机。完整配对样本为 400 对，但完整变化矩阵可唯一归类的只有 187 对（46.75%）；另外 213 对仍有未决因素。以下不是人工 gold 结论，也不能从观察数据识别模型内部的因果机制。

## 优先动机一：保留主体，并不意味着保留主体的真实细节

| 自动成分统计 | 数值 | 分母 |
|---|---:|---|
| 真实实体直接删除 | 768 / 2,272 = 33.80% | 原文被判为支持的实体 |
| 真实属性直接删除 | 194 / 390 = 49.74% | 原文满足严格主体支持条件的支持属性 |
| 属性删除时主体仍保留 | 127 / 194 = 65.46% | 确定直接删除的真实属性 |
| 属性随主体一起删除 | 67 / 194 = 34.54% | 同上 |

这提示应该单独研究“主体仍在，属性退化”的现象，不能仅凭 object 保留率评价 steer 是否保住真实内容。属性删除比例高于实体，但两种成分的原始分布、抽取误差与视觉难度不同；这里不声称它们具有同等测量误差，也不把比例差解释成因果效应。

下一步先复核这 127 条属性及其前后主体身份。若成立，首个受控实验可以只改变属性保护条件，固定基础 steer 强度、层、解码方式和样本；先考察严格真实属性保留率是否改善，再观察实体幻觉是否反弹。暂不同时改变 steer 方向、多个层与强度。

## 优先动机二：幻觉减少经常伴随真实成分的删除和替换

395 对变短样本中，184 对可唯一归类。在这 184 对里，有 79 对属于“幻觉减少”：

| 真实信息变化 | 对数 |
|---|---:|
| 不变 | 2 |
| 仅增加 | 2 |
| 仅丢失 | 17 |
| 有增有减 | 58 |

因此，这个已归类子集中有 75/79（94.94%）对同时出现了真实成分丢失，其中 58 对还增加了其他真实成分。相对于全部 395 对变短样本，已观察并唯一归类到这些单元格的 75 对占 18.99%。其余未决者可能改变总体分布，不能把 94.94% 写成所有 steer 样本的结论。

这支持关注删除的选择性，以及“新的真实内容是否掩盖了原有真实内容的损失”。样本 260370 中，缩短文本删掉了被判为幻觉的 truck、traffic light，同时省略原图可见的 building、sign；527219 则提供了去掉 person 幻觉而保留已提取真实成分的对照。详见 [图片对照记录](CASE_REVIEW.md)。

先在复核后比较这两类样本，确定真实损失主要是背景主体还是已保留主体的属性。若主要是后一类，优先与动机一合并，避免同时展开多个改动变量。

## 辅助观察：词数下降不能直接换算成信息损失

- 总词数 35,191 → 16,951，下降 51.83%。
- 严格口径下已判为支持的实体与属性总数 2,662 → 2,341，净下降 12.06%。这是前后计数差，包含新增内容的抵消，不能当作真实信息保留率。
- 重复提及代理量 1,785 → 1,027，下降 42.46%。它由同一抽取实体的额外提及次数计算，不包含全部冗余表达。
- 变短组 POS 净减少包括 NOUN 4,679、PROPN 59、ADJ 1,582、VERB 2,578；其余词类也有明显减少。词类与语义成分不是一一对应关系，动词减少不能在当前实体/属性框架中自动解释成动作关系丢失。

这些数值提示词汇压缩、重复提及减少和语义内容变化可能共存，但它们不是可以直接相加的原因分解。需要先利用逐词与逐事实明细做配对复核，再定义后续干预指标。

## 最先复核的测量边界

1. 实体到属性的表达变化，例如 543118 的 `mirror` 与 `mirrored wall`，可能同时涉及表示转换和描述范围改变；不能只看增删计数。
2. 67 对有分解异常，166 对含语义对齐未决，186 对含视觉不确定事实；这些集合重叠，不能相加作为失败率。
3. 有 20 条属性被判为支持但主体非支持，其中主体不确定 6 条、主体幻觉 14 条。严格属性统计已排除这些记录。
4. 47 张图片有历史开发重叠。本轮适合寻找动机，不能充当独立测评准确率。

本轮保留全部原始结果，不为获得更好的比例而改写标签、放宽未决规则或重新挑选样本。完整数据见 [实验报告](RESULTS.md) 与 [逐样本审查页面](observations/case_gallery.html)。
