**已完成代码修改、参考标注和真实 API 实验。8-shot 在本轮隔离验收集上的严格参考匹配 F1 为 65.9%，零示例为 53.1%。有所改善，但尚未通过语义稳定性验收。**

这里的标签由助手在预测前制作并冻结，尚未经用户或独立人员审核。指标是对参考结构的匹配，不是已认证的人工语义准确率。保留所有失败、额外事实、缺失事实和未决记录，供后续裁定。

共 **45 次拆分、96 次实际 HTTP 请求**，41 次成功、4 次失败。正常每条两阶段；有界重试增加请求，A 阶段失败则不发 B 阶段。用户已明确授权具体数据包及官方目的地。未发生额外授权范围外的实验。

## 五类独立指标

评分先按实体 canonical/kind/组链接及 mention 对齐，再匹配类型、角色、关系端点、数量单位/比较器、语气、否定和事件作用域。ID、排列和 source 措辞不直接计分。失败 caption 以空预测纳入召回，不能通过删除失败样本抬高成绩。

以下为**运行前冻结评分协议**的结果；未知谓词及报警事实照常保留。P/R/F1 单位为 %。

## 重复稳定性与伪消失

3 条 caption 各独立运行 3 次，共 9 个运行对：

- 花瓶短句：三次输出归一化后事实一致，三个比较对 F1=100%。
- 两双鞋短句：三次输出归一化后事实一致，三个比较对 F1=100%。
- 长颈鹿长句：第一次有输出，第二、三次均在 B 阶段引用冻结表中不存在的实体，修复仍失败。两个有效/失败比较对 F1=0，双失败对没有可定义的事实 F1。

**完整有效的比较对为 6/9**。六个有效对的条件 F1 为 100%；计入有效/失败对的 pooled F1 为 **85.2%**，双失败对没有事实分母。因此绝不能只报道“稳定性 100%”。

4 组同义改写：

| 改写基例 | 结构匹配 F1 | 基句预测的伪消失率 |
| --- | ---: | ---: |
| 花瓶 | 62.1% | 40.0% |
| 长颈鹿短句 | 100.0% | 0.0% |
| 热狗 | 66.7% | 33.3% |
| 两双鞋 | 100.0% | 0.0% |

改写 pooled F1=**77.9%**；按 caption 平均伪消失率 **18.3%**，4 个图片对的 bootstrap 95% 区间为 **0.0%–36.7%**。小样本区间仅供诊断，不能作显著性结论。花瓶中包含同义映射遗漏和范围外事实变化；热狗中 peppers 的 kind 在 single/group 之间改变。这一指标是当前完整拆解/规范化/对齐协议的伪消失，不等同于纯模型语义遗漏率。

## 使用结论

当前版本可继续用于人工审核和开发实验，**不宜直接用小幅 retained/removed 差异支持论文结论**。下一步优先核定 Attribute 范围、复合对象、整体/部分关系方向、推测语气及 missing_anchor 策略，再扩展独立审核的图片验收集。Count 的小样本满分、受限合成变化的满分，都不足以替代真实 caption 的可靠性检验。

机器可读指标：metrics.json；逐条误差：metric_details.json；完整模型记录：results.jsonl / checkpoints/；便于人工查看的实体/事实表：MODEL_OUTPUTS.md。所有原始数据保留，没有覆盖 v4 或本轮冻结标注。
