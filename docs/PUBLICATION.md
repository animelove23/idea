# 发布内容与边界

包含最新候选框架、依赖的 Final v1／早期分析模块、固定 prompts/few-shot 示例、开发测试、400 对输入文本、阶段观测与汇总、历史报告和研究背景。

`outputs/final_v1_release/` 与 `outputs/final_v1_m5/` 下仅提交运行必需的 profile、路由和示例；它们是历史路径兼容资源，不代表公开包包含完整旧实验。其他运行结果写入被 Git 忽略的 `outputs/`。公开统计放在 `results/`。

不含 API key、本地服务配置、COCO 图片/标注全集、环境、生成器权重、原始响应缓存及约四万份冻结副本。随包保留示例和测试依赖的 28 个历史图像文件（约 4.6 MB），以 manifest 记录哈希；部分文件是不同编码的历史版本，不用官方同 ID 文件静默替换。400 张实验图由官方数据集另行准备。数值汇总不能取代原始审计数据。数据集图片和上游数据许可归原权利方，保留旧仓库 MIT LICENSE 不改变这些数据的许可。

`docs/history/reports/` 和旧背景说明是历史文档，里面的命令可能依赖当时完整工作区。归档中的本机目录前缀替换为相对前缀，示例图片改为随包 assets 相对路径；历史 manifest 的原文件哈希不能用于验证这些经过路径重写的发布副本。当前包独立记录发布元数据。离线测试的配置改用临时虚拟密钥与模拟传输，不读取本机密钥；运行时模型逻辑未因本次整理改变。

支持的运行方式是仓库根目录下使用默认附带路由运行最新端到端入口。Python 3.12 与 spaCy en_core_web_md 为本次验证环境；其他系统可安装同依赖自行运行，未声称已跨平台实测。旧的实验生成器／批次脚本按历史代码保留，不保证脱离原始 outputs 可以执行。

API 配置模板为空，本地填写 `deepseek-flash` 与官方地址。代码同时固定阶段模型名；如果服务将来更改可用模型名，应新建实验条件并重新验收，不能静默替换后沿用历史分数。

研究参考采用 FAITHScore 的原子事实分解后验证思路；本工程进一步按两段文本对齐事件组织观察。不要把当前实体／属性统计命名为论文原版 FAITHScore 或 CHAIR 的官方测评结果。[早期参考笔记](../decomposition/FAITHSCORE_REFERENCE.md)记录具体实现背景。
