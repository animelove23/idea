# v1.2：格式错误、语义待审和辅助字段告警分开

根据30对真实样本的实际原始响应调整。用户已裁定：正在发球/准备发球为 ambiguous；several/few 为 modified。Decomposer、事实格式、8-shot文件、旧实验和冻结参考不改动。

## 保留的结构检查

JSON/字段/状态非法、未知ID、重复实体ID、事实绑定缺失、引用不在原文、错误单侧/双侧结构、extraction_gap没有对侧原句证据仍拒绝。真正冲突的确定事实配对仍待审，程序不随意选一个。主事实恰好计一次，关联引用不重复计数。

## 修改的条件

| 旧条件 | v1.2 |
| --- | --- |
| 同实体出现多个候选组就整对失败 | 完全重复记录去重；重叠ambiguous候选取并集；相互冲突的确定实体对应局部合成ambiguous，保留未受影响的确定对应 |
| 实体映射不确定，所有确定状态一律拦截 | 跨句实例对应仍不强行retained/modified；未知实例的存在性删除/新增仍待审。属性、关系、数量等整句层面的added/removed允许模型判断，记录one_sided_caption_judgment告警，不把映射缺失视为删除证据 |
| 没有实体ID，天气/照明也失败 | 有真实原文出处的单侧场景事实允许added/removed，不强造实体。跨句缺乏可靠绑定仍保持待审 |
| 参与实体列表顺序必须完全一致 | 同一集合的成员排列变化，在已知集合谓词和相同位置端点下允许；显式above/below等反向等义也允许；方向角色互换或端点改变仍转语义待审 |
| modified必须slot字符串相等 | 优先参考现有事实类别，普通slot命名差异只告警；材质/颜色等明确维度冲突、明确计数集合变化仍转语义待审 |
| 类型、语气、参与者边界不满足就是结构失败 | 保留原有事实对应组，转ambiguous并写semantic_reviews，保存model_proposal；不再拆散成无对应的技术占位 |

`rejected_alignments` 是结构/引用/冲突问题；`semantic_reviews` 是由规则转成ambiguous的语义问题；`warnings` 表示没有否决模型的辅助字段问题。`ready`仍只表示没有拒绝或强制待审，不表示语义正确。

## 不能据此保证的事情

辅助字段不能证明语义等价，移除不合理否决也不能证明模型正确。对材料与颜色两个独立事实，程序不会自己创造removed+added；它将错误的modified提议转待审。新增提示词要求模型阅读全文，对未知实例的单侧事实特别排查局部保留和候选指称。

当前没有新的LLM请求。29条已保存事实响应用新校验回放；264423原来在实体阶段停止，没有事实响应可回放。实体现在可恢复，并不等于其事实步骤已经通过。

回放相对旧校验的联合F1从78.81%到85.46%，技术回退78到26条；这些包含语义规则转待审带来的得分，不能称新提示词或模型变好。确认误删除仍2条，部分保留却判删除由4增至5条，绝对错误未减少。应继续审查新放行的单侧判断，而不能只看比例下降。
